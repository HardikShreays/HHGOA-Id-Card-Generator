# HH Goa PFP Frame - Figma Starter

Import this file into Figma:

`assets/HH_Goa_PFP_Frame_Figma_Starter.svg`

## Use

1. Drag the SVG into a Figma design file.
2. Ungroup it to edit the named layers.
3. Place a square profile photo behind the SVG.
4. Center the photo under the transparent circular opening.
5. Edit or hide the `06_Optional_Name_Overlay` group.
6. Export the complete selection as a 1200 x 1200 PNG.

## Dimensions

- Canvas: `1200 x 1200`
- Transparent photo opening: centered at `600, 600`
- Photo opening radius: `444`
- Recommended photo area: `888 x 888`, starting at `156, 156`

## Fonts

- Imbue for display text
- Victor Mono for labels

Install the included project fonts before editing text in Figma.
