# HH Goa ID Card — Figma Starter

Import this file into Figma:

`assets/HH_Goa_ID_Card_Figma_Starter.svg`

## Import

1. Open a Figma design file.
2. Drag the SVG onto the canvas, or choose **File → Place image**.
3. Right-click the imported design and choose **Ungroup** until the named groups are editable.
4. Keep the outer frame at **1080 × 1350 px** so it matches the generator.

## Fonts

Install these included fonts before editing text:

- `public/fonts/Imbue-Bold.ttf` — names and display text
- `public/fonts/VictorMono-Variable.woff2` — labels, roles, IDs, and social handles

Restart the Figma desktop app after installing them.

## Generator-compatible areas

- Canvas: `1080 × 1350`
- Photo slot: `x 72`, `y 224`, `628 × 776`, radius `24`
- Name starts at `x 72`, `y 1028`
- Role starts at `x 76`, `y 1110`
- Builder title starts at `x 76`, `y 1158`
- QR area: `x 850`, `y 1080`, `152 × 152`

The SVG contains example text and a vector photo placeholder. Replace them in Figma, then export a PNG for visual review or keep the edited SVG as the implementation reference.
